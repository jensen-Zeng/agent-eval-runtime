# 本机控制台（v1.2）

AgentEval 提供一个嵌入 Go Runtime 的中文网页控制台。前端资源随程序编译，不需要 Node.js、npm 或外部 CDN。启动 Runtime 后，在本机浏览器打开 `http://127.0.0.1:8787/`（端口以配置文件 `server.listen` 为准）。

## Windows 启动

双击仓库根目录的 `打开控制台.cmd`。公开仓库使用 `configs/local.json`；若本机另有 `configs/e3-local.json`，脚本会优先使用该本地配置；也可以在 PowerShell 里指定配置：

```powershell
.\scripts/start-ui.ps1 -ConfigFile configs\local.json
```

启动脚本使用现有的 Runtime 启动流程和预建镜像。第一次启动前仍需完成 Go、Docker、PostgreSQL 与任务环境准备。Runtime 在当前窗口前台运行；关闭该窗口会停止服务。辅助进程最多等待 300 秒检测 `/readyz`，服务就绪后打开浏览器，不负责启动或关闭 Runtime。

## 实验台

实验台列出已经登记的任务，可按任务名、任务 ID 和来源搜索并多选。每项显示冻结在任务登记信息中的运行预算和资源限制。镜像、worker 数量及队列容量来自 Runtime 配置，当前界面不修改这些环境级选项。

方案包含标题、模型列表、每项重复次数和是否加入基线运行。重复次数允许 1 到 100。方案可以保存、载入和删除；实验提交后会出现在“运行记录”。基线运行不调用模型。真实模型运行可能产生服务商费用；启动前需要解锁本机密钥库。

已有任务可跨数据集组合运行，应用层实验格式不限定 E3。新题包仍须先通过数据集导入流程登记；缺少评分器或任务环境不受支持时，控制台不会将它们伪装成通过。

## 运行记录

记录页显示实验状态与每项任务结果。展开任务可以读取 Run 报告和分页执行事件，每页最多 100 条、最多浏览 100 页。完成实验后可导出证据包；实验完成表示结果采集结束，并不代表每项评分通过。支持恢复未完成实验、取消运行、下载实验 JSON/CSV，以及导出证据目录。页面在浏览器后台时暂停状态轮询，返回前台后继续刷新。

## 模型连接与密钥

连接设置保存 OpenAI-compatible Endpoint、默认模型和重试次数到 `configs/ui/provider.json`。API Key 使用主密码加密后写入 `configs/ui/keyvault.json`，两份文件均位于 Git 忽略的 `configs/ui/` 目录。页面不使用浏览器存储保存密钥，API Key 不通过 GET 返回；保存或解锁后会清空输入框。解锁状态只保留在 Runtime 进程内存，重启后需要再次输入主密码解锁。

主密码至少 12 个字符。密钥库使用 PBKDF2-SHA256（600,000 次迭代）派生 AES-256-GCM 密钥。更新已经存在的 API Key 需要输入当前主密码；忘记主密码后，旧 Key 无法解密恢复。请为这两份本机配置文件做好合适的备份与访问权限控制。

密钥库锁定期间不能开始新的模型实验。服务重启后，已排队模型任务被 worker 领取后会等待解锁，仍可被取消；解锁已有密钥库不会修改连接或 Key，因此允许在等待期间操作。已执行但在重启时中断的任务按既有恢复策略记录为基础设施中断，不自动重新计费执行。完成后台任务后，可以从连接设置手动锁定。真实模型请求会产生服务商费用，请在提交实验前核对模型列表与重复次数。

## 本地安全边界

页面资源通过 Go `embed` 编译进 Runtime，仅提供首页、CSS 和 JavaScript；页面和 `/v1` API 使用同源请求，并设置严格内容安全策略。服务应绑定回环地址供本机使用，不要将带有已解锁密钥库的控制台直接暴露到公网或不可信网络。

## 容量与当前限制

网页同时最多协调 2 个实验，单实验最多 1,000 个任务运行，重复次数 1–100；最多保存 500 个方案及 500 条网页实验。重试次数为 0–2。证据导出全局串行，单次导出沿用 512 MiB 上限并核对冻结清单；JSON 请求、文件读取和协调日志均有大小限制。实验文件位于 `artifacts/ui/experiments/`，方案位于 `artifacts/ui/presets/`，这些目录随服务 artifacts 配置改变。

目前没有全局磁盘配额或网页历史归档功能，长时间使用应管理 artifacts 的磁盘空间。取消是异步请求；与正在提交的 HTTP 请求交错时，少量未写回清单的 job 可能需要通过队列记录核对，不宣称瞬时强制终止所有进程。模型资源来自既有任务预算，网页不能发送任意 Docker 参数或修改 grader。网页目前用于可信本机单用户，无公网账户与租户管理。

本次交付验证见 v1.2 运行验收（本机历史记录，不随仓库发布）。Linux 使用同一 Go 源码与内嵌网页；本次只验证 Linux 可执行文件构建，Windows 双击脚本不适用于 Linux。
